# PPT 협 AI Native (ppt-hyeop-ainative)

마크다운으로 쓰면 흰 배경 + Pretendard의 강의 슬라이드로 렌더링해 주는 로컬 PPT 소프트웨어. 제가 AI 네이티브 강의를 할 때 실제로 쓰던 도구를 그대로 배포합니다.

파워포인트도, 디자인 툴도 없습니다. **폴더 하나 = 발표 하나 = md 파일 하나.** 옵시디언(또는 아무 에디터)에서 md를 고치면 브라우저 슬라이드에 실시간 반영되고, 버튼 하나로 벡터 PDF가 나옵니다.

## 시작하기

```bash
npm install        # 최초 1회
start.bat          # 서버 시작 + 브라우저 자동 열림 (http://localhost:7744)
```

Windows 기준이며 Edge 또는 Chrome이 설치되어 있으면 PDF 출력까지 바로 동작합니다. (서버를 끄려면 `stop.bat`)

## 사용법

1. 이 폴더 안에 새 폴더를 만든다 - 예: `내발표/`
2. 서버가 자동으로 `내발표.md`와 뷰어(html)를 만들어 준다
3. md를 편집하면 브라우저에 실시간 반영
4. 이미지는 그 폴더(또는 폴더 안 `assets/`)에 넣고 `![[이미지.png]]`로 호출
5. 발표는 F키 전체화면 + 방향키, 배포는 **PDF 저장** 버튼

`sample/` 폴더에 모든 슬라이드 타입이 들어 있는 예제가 있습니다. 열어서 고쳐보는 게 가장 빠릅니다.

## 마크다운 문법

슬라이드는 `---`로 구분하고, 각 슬라이드 첫 줄에 `@type`을 지정합니다.

| @type | 용도 |
|-------|------|
| `@typeTitle` | 타이틀 (104px, 900 weight) |
| `@typeHead` | 섹션 제목 (72px) |
| `@typeList` | 리스트 |
| `@typeImage` | 이미지 중심 |
| `@typeTable` | 표 중심 (영역 초과 시 자동 축소) |
| `@typeMermaid` | mermaid 다이어그램 |
| `@typeCode` | 코드 셀 |
| (없음) | 본문 슬라이드 |

인라인: `**볼드**` · `==형광펜==` · `` `코드` `` · `![[이미지]]` · `|표|`

## 이미지 정리

이미지가 여기저기 굴러다니면:

```bash
node scripts/organize.js          # 어디로 옮길지 보고만 (드라이런)
node scripts/organize.js --apply  # 각 덱이 참조하는 이미지를 그 덱의 assets/로 이동
```

어떤 덱도 호출하지 않는 이미지는 자동으로 옮기지 않고 목록만 보여줍니다. Claude Code와 함께 쓰면 알아서 물어보고 처리해 줍니다.

## 스타일 커스터마이징

`style.md`의 값을 바꾸면 저장 즉시 모든 슬라이드에 반영됩니다 (글자 크기, 자간, 여백 전부).

## PDF

**PDF 저장** 버튼 = 서버사이드 Puppeteer 벡터 PDF. 270장 기준 약 12초, Ctrl+F 검색·드래그 선택 가능한 텍스트, 합리적인 파일 크기. 브라우저에서 본 것과 동일하게 나옵니다.

- 브라우저를 못 찾으면: 환경변수 `CHROME_PATH`에 Edge/Chrome 실행 파일 경로 지정

## Claude Code와 함께 (선택)

이 폴더에서 Claude Code를 열면: 초안 생성("이 원고로 슬라이드 md 만들어줘"), 이미지 정리, 스타일 조정을 대화로 처리할 수 있습니다. 직접 쓰는 것이 기본 의도이고, 생성은 보조입니다. 상세는 `SKILL.md`.
