# PPT 협 AI Native

마크다운으로 쓰면 강의 슬라이드가 되는 도구입니다. 제가 AI 네이티브 강의를 할 때 실제로 쓰던 것을 그대로 공개합니다.

파워포인트 없이, **폴더 하나 = 발표 하나 = 글 파일 하나.** 글을 고치면 슬라이드에 바로 반영됩니다.

## 시작하기

**Claude Code에 이 페이지 주소를 주면서 "나 이 소프트웨어 쓰고 싶어"라고 하세요.** 설치부터 실행까지 알아서 해줍니다.

설치가 끝난 뒤에는, 폴더 안의 **`start.bat`을 더블클릭**하면 됩니다. 저게 뭔지 몰라도 됩니다 - 누르면 브라우저에 슬라이드가 열립니다.

## 사용법

1. 이 폴더 안에 새 폴더를 만든다 - 예: `내발표/`
2. 그 안에 `내발표.md` 파일이 자동으로 생긴다
3. md 파일에 글을 쓰면(옵시디언, 메모장 뭐든) 브라우저에 실시간 반영
4. 이미지는 그 발표 폴더 안에 넣고 `![[이미지.png]]`로 부른다 - 이것도 Claude Code한테 "이미지 넣어줘"라고 시킬 수 있습니다
5. 발표할 때는 F키(전체화면) + 방향키, 파일로 보낼 때는 화면 위 **PDF 저장** 버튼

`sample/` 폴더에 모든 슬라이드 종류가 들어 있는 예제가 있습니다. 열어서 고쳐보는 게 가장 빠릅니다.

## 슬라이드 쓰는 법

슬라이드는 `---`로 나누고, 각 슬라이드 첫 줄에 종류를 적습니다.

| 첫 줄 | 어떤 슬라이드가 되나 |
|-------|------|
| `@typeTitle` | 큰 타이틀 |
| `@typeHead` | 챕터 제목 |
| `@typeList` | 리스트 |
| `@typeImage` | 이미지 한 장 |
| `@typeTable` | 표 |
| `@typeMermaid` | 다이어그램 |
| `@typeCode` | 코드 |
| (안 적으면) | 일반 본문 |

글 안에서: `**볼드**` · `==형광펜==` · `|표|`

## 바꾸고 싶으면

글씨 크기, 여백, 색 같은 게 마음에 안 들면 Claude Code에게 "글씨 더 키워줘"라고 말하면 됩니다. 뭔가 안 되거나 이상할 때도 마찬가지입니다.
